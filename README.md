# Marketing Campaign Analysis | Excel

## Project Overview
This project analyzes the performance of six marketing campaigns using Microsoft Excel functions. The goal is to evaluate campaign profitability, advertising spend, and return on investment to support better marketing decisions.

## Business Questions
- Which campaigns generated the highest profit?
- How efficiently was the advertising budget used?
- Which campaigns achieved the best ROI and ROAS?
- What share of total revenue came from each campaign?

## Tools & Techniques
- Microsoft Excel
- Excel Functions: SUMIF and other analytical formulas
- Campaign performance calculations
- ROI, ROAS, profit, and revenue share analysis

## Key Metrics
- Total Advertising Spend
- Revenue / Return
- Profit
- Return on Investment (ROI)
- Return on Ad Spend (ROAS)
- Revenue Share

## Project Workflow
1. Reviewed and organized campaign data.
2. Used Excel functions to calculate campaign-level metrics.
3. Compared spending, revenue, and profitability across six campaigns.
4. Analyzed ROI and ROAS to evaluate campaign efficiency.
